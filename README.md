# GameBoard

Tyler's sketch — a game board floating above the clouds — rebuilt as a real
Unity scene (Unity 2022.3.62f1).

- **The board**: one solid pale slab with a BoxCollider
  (`GameBoard`, 10 × 1 × 6.6 units, top at y = 0).
- **The pieces**: five semi-transparent red oval discs (`Piece_1`..`Piece_5`),
  back row of three + front row of two, matching the markers in the sketch.
- **The background**: the clouds from Tyler's own photo, cleaned of the ink
  linework (see `tools/make_cloud_textures.py`), on two large planes at
  different depths. Each carries a single non-repeating texture
  (Wrap = Clamp) and is driven by `Assets/Scripts/ParallaxLayers.cs` —
  camera-relative parallax plus a very slow automatic drift.

## How the scene is built

The scene is generated by an editor script — no hand-written scene YAML:

- `Assets/Editor/BuildGameBoardScene.cs` — builds and saves
  `Assets/Scenes/GameBoard.unity`.
- `Assets/Editor/GameBoardScreenshot.cs` — rebuilds the scene and renders
  the Main Camera to `Screenshots/gameboard.png` (1920×1080).

## CI

The **Screenshot GameBoard** workflow (manual dispatch) installs Unity
2022.3.62f1 in GitHub Actions, builds the scene, renders the screenshot,
and uploads the PNG, the built scene, and the editor log as artifacts.
It needs the `UNITY_USERNAME` / `UNITY_PASSWORD` repo secrets
(Unity Personal license activation), same as Tyler's other Unity repos.
